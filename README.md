# Easybeekeeper
Módulo IoT para monitorização de colmeias com ESP32. Regista peso (HX711/células de carga), temperatura/humidade (DHT22) e tensão da bateria. Inclui controlo climático ativo (ventoinha 5V via relé) e sistema solar off-grid (bateria 18650, TP4056 e Step-Down). Dashboard web responsivo com alertas em tempo real e estado da colheita.
